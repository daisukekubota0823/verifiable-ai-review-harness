# Benchmark domain 3 — microscopy quantification (specification)
- Images: 154 synthetic SEM-style images with known ground truth (7 conditions x 22 replicates; seeds offset +500000 from the original 21-image validation, which is not reused). Quantification by the same pipeline and centroid matching as the validated SEM workflow.
- QC judgment cases (154, one per image): does the image's quantification pass the registered acceptance criteria — miss rate <= 0.05, false-positive rate <= 0.05, area-fraction absolute error <= 0.5 percentage points, median diameter relative error <= 0.05 (all must hold)? Truth is mechanical from the per-image metrics. Borderline: any metric within margin (0.01 / 0.01 / 0.1 pp / 0.01) of its line; routed to human review by design, scored separately.
- Verification statements (146): claims about a per-image record (detected count, estimated area fraction, missed count), half supported and half carrying one controlled fault (a value taken from another image, a perturbed value, an incremented miss count). Each exists in English and Japanese versions with identical values and ground truth; the evidence excerpt shown to the judge contains every value needed.
- Construction: build_micro.py. Scoring: QC — agreement, kappa, miss, false-fail; verification — agreement, kappa, dangerous miss, false flag; per language, overall and on the auto-judged subset.
